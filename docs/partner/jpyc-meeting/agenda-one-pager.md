## 想定構成の共有（5〜10分）

- **オペレーター**：TOKYO307（ブランド：Sealith）。eSIM 商品は [lifetime-esim.com](https://lifetime-esim.com)。  
- **決済の二系統**：既存の Stripe に加え、JPYC での商品代金支払いを PoC 対象とする。  
- **JPYC EX の位置づけ**：人／法人オペレーターが WebView 経由で発行・償還（オンランプ）。コネクタは金額・ネットワーク選択・リダイレクト等の UX を提供。KYC と最終確認は JPYC 側。  
- **ノンカストディ**：利用者は自己管理ウォレット。当社受取は Safe を想定。Sealith は利用者の JPYC／秘密鍵を預からない。  
- **Staffpass（軽く言及）**：AI社員（Grok Bot）の承認・上限・監査レイヤ。エージェント起点の購入を人が止められるガバナンスであり、**JPYC API そのものの主題ではない**。

> 詳細フローは別紙「アーキテクチャ概要」を参照。
