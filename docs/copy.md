# コピー一覧 — Staffpass / AI社員

## ブランド

- **Sealith の Staffpass** / **AI社員**（就業規則と日報。手足は差し替え可能・まず Grok Bot）
- Sealith = この制御面を作っている会社。Staffpass = 製品名
- 対象: 日本の中小・零細の経営者・幹部（情シス専用フレーミングにしない）

## 物語の型（経営者向け）

1. **手足は優秀（具体）** — Grok Bot: 自分専用クラウドPC、実アプリ／ブラウザ、端から端まで、24時間、始めやすい、要承認時は個人 Auto-review で戻る。ChatGPT / Claude なども手足としての実行力は同様に強い。
2. **でも会社の制御は足りない（手足共通）** — 共有PC・共有ログイン、職務／上限の割当、確定操作の人ゲート、説明できる台帳。「お願い」だけでは足りない。Bot分割＝安全境界とは言わない。
3. **Sealith の Staffpass が埋める** — 社員証・社長承認・台帳・上限。どの手足でも同じ穴。まず Grok（本線）、他は順次（未接続）。

## H1 / メイン

- **AIを入れるな。AI社員を雇え。**

## サブ（ヒーロー）

- Grok Bot の具体的な強さ → 他エージェントも手足として同様に強い → 足りないのは会社側の制御 → Sealith の Staffpass は就業規則と日報。まず Grok Bot から本線対応。

## 機能見出し

| 機能 | 一言 |
|------|------|
| 社員証 | 誰が・何の仕事で・どこまで。止められる。 |

| あとから説明できる記録 | 誰が・何目的で・何をしたか。上司・取締役会にも。 |
