# コピー一覧 — Staffpass / AI社員

## ブランド

- **Staffpass** / **AI社員**（就業規則と日報。手足は差し替え可能・まず Grok Bot）
- 対象: 日本の中小・零細の経営者・幹部（情シス専用フレーミングにしない）

## H1 / メイン

- **AIを入れるな。AI社員を雇え。**

## サブ

- 権限・承認・記録がついたAI社員を雇う話。共有PCでも「誰が何をしてよいか」を分けられる。
- Staffpass は就業規則と日報。手足のエージェント基盤は差し替え可能（まず Grok Bot）。

## 機能見出し

| 機能 | 一言 |
|------|------|
| 社員証 | 誰が・何の仕事で・どこまで。止められる。 |
| 社長が止める承認 | 危ない操作は人が見てから。承認されるまで実行しません。 |
| あとから説明できる記録 | 誰が・何目的で・何をしたか。 |

## 導入モード（表向け）

- おまかせ導入（旧 Managed）
- 今の Grok Bot に載せる（旧 BYO）

## ダッシュボード用語（経営者向け）

| 避けたい語 | 言い換え |
|------------|----------|
| credentials破綻 / needs_reauth | 再接続が必要 / 接続が切れた AI社員がいます。記録は残したまま、つなぎ直しが必要です |
| fail-closed | 承認されるまで実行しません |
| Gateway / binding | Staffpass経由 / 接続状態 |
| BYO | 今の Grok Bot に載せる |
