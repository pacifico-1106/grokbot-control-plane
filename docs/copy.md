# コピー一覧 — AI社員 for Grok Bot

## H1 / メイン

- **AIを入れるな。AI社員を雇え。**

## サブ

- 動くだけのボットではなく、職務分掌・承認・監査がついた「説明できる AI 社員」を Grok Bot の上に載せる。
- 手足の環境は共有でも、できることと残るログは分けられる。

## 短句

- 禁止するな。説明できるレールを敷け。
- 同じ箱でも、営業Botと経理Botで権限もログも違う。
- 決済レールは借りる。説明責任の台帳は自前。

## 機能見出し

| 機能 | 一言 |
|------|------|
| 社員証 | 職務・目的・スコープ・期限。失効できる。 |
| 承認ゲート | 危険操作は人間が許可してから実行。 |
| 監査 | 誰が・何目的で・何をしたかの構造化証跡。 |

## トーン

- 中小企業の経営者・情シス向け。威圧せず、実務言葉。
- ダッシュボード UI は Grok Bot 製品クロムに寄せる（ダーク・ニュートラル・余白控えめ）。
- 紫の汎用 SaaS 感は避ける。
