## 2. 扱う主なデータ

| 種別 | 例 | 備考 |

## 4. 保管・分離・委託（概要）

- **委託先の例:** クラウドホスティング、DB／Auth、Stripe、メール配信、外部 AI／Bot。最新一覧は審査時に個別開示。
